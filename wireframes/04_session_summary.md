## Elements

### Session Header
- Congratulatory message
- Personalized with username
- Celebration emoji

### Key Metrics (Top Cards)
- **Duration**: Total session time
- **Signs Practiced**: Count of unique signs
- **Overall Accuracy**: Success percentage
- **Correct/Incorrect**: Detailed breakdown
- **Average Time**: Response time per sign

### Performance Table
- Per-sign breakdown with:
  - Sign letter
  - Attempt count
  - Success rate (correct/total)
  - Current mastery percentage
  - Mastery change (+/- %)
  - Trend indicator (⬆️ ⬇️)
- Expandable to show all signs

### Achievements Section
- Session-specific achievements
- Streak tracking
- Motivational badges

### Recommendations
- AI-powered suggestions
- Focus areas based on performance
- Specific improvement tips

### Action Buttons
- **View Detailed Analytics**: Deep dive into progress
- **Practice Again**: Start new session
- **Return to Dashboard**: Go to main menu

## Data Visualization Opportunities
- Accuracy trend chart
- Mastery progress bars
- Time distribution graph
- Success rate by sign (bar chart)
