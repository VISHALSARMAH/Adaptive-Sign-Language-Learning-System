## Responsive Design Breakpoints

### Mobile Portrait (320px - 479px)
- Stack all elements vertically
- Single column layout
- Touch-friendly buttons (min 44×44px)
- Simplified navigation
- Collapsible sections

### Mobile Landscape / Small Tablet (480px - 767px)
- Two-column grid for stats
- Larger webcam preview
- Side-by-side buttons

### Tablet Portrait (768px - 1023px)
- Three-column layout for stats
- Enhanced table views
- Expanded navigation menu

### Desktop (1024px+)
- Full multi-column layout
- Sidebar navigation
- Side-by-side panels
- Maximum content density

## Touch Interactions

### Gestures
- **Tap**: Primary action
- **Swipe Left/Right**: Navigate between signs
- **Pinch**: Zoom webcam preview
- **Long Press**: Show sign details

### Button Sizes
- Minimum: 44×44px
- Recommended: 48×48px or larger
- Spacing: 8px between interactive elements

## Accessibility Considerations

### Visual
- High contrast mode for mobile
- Larger text options (1.5× - 2×)
- Icon + text labels

### Audio
- Screen reader support
- Text-to-speech feedback
- Haptic feedback on actions

### Performance
- Lazy loading images
- Reduced animations on low-end devices
- Progressive Web App (PWA) support
